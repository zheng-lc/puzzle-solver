# puzzle-solver — 3x3 八数码拼图求解器

基于 **A\* 搜索算法** 的 3x3 八数码拼图（8-puzzle）最优解求解器，使用 Rust 编写。

给定任意 9 位棋盘字符串（`0` 表示空位，`1-8` 表示拼图块），程序先判断可解性，再用 A\* 搜索求出**步数最少**的移动序列。

## 特性

- ✅ **最优解保证**：A\* + 曼哈顿距离启发式（可采纳启发式），返回步数最少的解
- ✅ **可解性预检**：基于逆序数奇偶性的数学判定，无解棋盘直接拒绝
- ✅ **输入校验**：长度、字符、重复数字、空位存在性检查，错误信息友好（中文）
- ✅ **高性能**：`BinaryHeap` 优先队列（O(log n) 取最小）、`HashMap` 状态去重、预计算目标位置表
- ✅ **测试完备**：12 个单元测试 + 1 个文档测试，全部通过
- ✅ **基准测试**：Criterion 基准套件（求解 / 启发式 / 可解性 / 解析）

## 使用方法

```bash
cargo run -- <9位棋盘字符串>
# 或
cargo run --release -- 504871623
```

**示例：**

```
$ cargo run -- 504871623
解法（共 23 步）：
587,645,678,654,78
```

输出说明：

- 解法为**移动序列**，每个数字表示被移入空位的拼图块编号
- 每 3 位加逗号分隔，便于阅读
- 已是目标状态时输出 `已经是目标状态！`；无解时输出 `此棋盘无解！`

**输入格式**：9 位字符串，行优先（左上 → 右下）排列，必须恰好包含 `0-8` 各一次。

```
输入 "504871623" 对应棋盘：

│ 5 │ 0 │ 4 │

│ 8 │ 7 │ 1 │
├───┼───┼───┤
│ 6 │ 2 │ 3 │
└───┴───┴───┘
目标状态：
┌───┬───┬───┐
│ 1 │ 2 │ 3 │
├───┼───┼───┤
│ 4 │ 5 │ 6 │

│ 7 │ 8 │ 0 │
└───┴───┴───┘
```

## 算法说明

### A\* 搜索

- **状态空间**：3x3 八数码共 9! / 2 = 181,440 个可解状态，A\* 在此规模下毫秒级完成
- **代价函数**：`f(n) = g(n) + h(n)`，`g` 为已走步数，`h` 为曼哈顿距离
- **启发式**：曼哈顿距离（各块当前位置到目标位置的曼哈顿距离之和），可采纳且一致，保证最优解
- **优先队列**：`BinaryHeap`（反转比较实现最小堆语义），弹出最小 f 值节点 O(log n)；f 相同时优先 h 更大者（更接近目标）
- **去重策略**：`g_scores: HashMap<Board, u32>` 记录已知最优 g 值，配合 lazy deletion 跳过过期堆条目
- **路径重构**：`node_store: Vec<AStarNode>` 以索引存父节点，O(路径长度) 回溯

### 可解性判定

将棋盘展平（忽略空位）后统计**逆序数**：逆序数为偶数则可解，奇数则无解。
